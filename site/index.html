Bordure & succès

Chaque succès obtenu pour la première fois agrandit la bordure du monde. Suis ta progression critère par critère.

–Succès restants
–Déjà obtenus

–Mode de récompense
Choisis ton pseudo pour suivre tes succès, critère par critère.

    Chaque succès agrandit la bordure une seule fois, pour le premier joueur qui l'obtient. Le gain s'ajoute au diamètre, donc la moitié de chaque côté. Sans joueur choisi, « À faire » et « Obtenus » parlent du serveur et la progression affichée est celle du joueur le plus avancé ; avec un joueur choisi, ils parlent de ce joueur. Les données sont relues sur le serveur toutes les 10 minutes environ, et Minecraft les enregistre toutes les 5 minutes.

    Rejoindre le serveur

    Serveur Minecraft Java sur liste blanche, pour les joueurs du Discord Suménium.

    1. Rejoins le Discord Suménium et passe la candidature avec le staff.
    2. Connecte-toi ici avec Discord (bouton en haut à droite), puis relie ton pseudo Minecraft Java dans Ma fiche et remplis-la.
    3. Le staff t'ajoute à la liste blanche une fois ta candidature validée.
    4. En jeu : Multijoueur → Ajouter un serveur → adresse play.sumenium.com, version Java 26.3.
